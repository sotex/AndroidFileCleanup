特性
--------

- **快速** 即使是较大的设备，也能在几秒钟内完成扫描！
- **多存储支持** 支持所有本地文件系统！
- **Material You** 适配您设备的主题！

安装
------------
获取[最新版本](https://github.com/newhinton/disky/releases/latest)的签名 APK，然后安装到您的手机上。

开发
------------

首先，请确保您已克隆此仓库：

```sh
git clone https://github.com/newhinton/disky

```

然后，您可以通过 Android Studio 或 CLI 正常构建应用：

```sh
# build
./gradlew assemble

```
